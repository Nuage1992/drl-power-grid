GitHub Pages 发布说明（Quarto 电网 DRL 项目）

这个版本已经按照 GitHub Pages + docs/ 文件夹 的方式配置好。

一、你平时编辑哪些文件？

通常只需要修改：

  • index.qmd：科研内容
  • styles.css：网页样式
  • images/：图片

不要手动修改 docs/ 中的文件，因为 docs/ 是 Quarto 自动生成的网站。

二、先在自己电脑预览

在 VS Code 中打开整个项目文件夹，然后打开：

index.qmd

点击 Preview。

也可以双击：

preview_local.bat

三、生成准备上传到 GitHub Pages 的网页

双击：

render_github_pages.bat

或者在 VS Code Terminal 中运行：

quarto render

完成后会自动产生：

docs/
├── index.html
├── images/
├── site_libs/
├── styles.css
└── ...

整个 docs/ 文件夹都是网页的一部分。

因此不要只上传 docs/index.html。

四、第一次上传到 GitHub

1. 在 GitHub 新建一个 repository

例如：

drl-power-grid

建议先选择 Public，方便分享。

2. 把这个项目中的全部文件上传到 repository

需要包含：

_quarto.yml
index.qmd
styles.css
images/
docs/
.nojekyll
README.md

其中 docs/ 非常重要，它包含真正发布的网站文件。

五、开启 GitHub Pages

进入你的 GitHub repository：

Settings → Pages

在 Build and deployment 中设置：

  • Source: Deploy from a branch
  • Branch: main
  • Folder: /docs

然后保存。

稍等一会儿，GitHub 会给你网站地址，通常类似：

https://YOUR-USERNAME.github.io/drl-power-grid/

以后把这个网址发给老师或其他人即可。

六、以后修改网站

以后流程非常简单：

修改 index.qmd / 图片
        ↓
Preview 检查
        ↓
quarto render
        ↓
docs/ 自动更新
        ↓
把修改后的文件 push / upload 到 GitHub
        ↓
网站自动更新

七、图片为什么不会丢？

当前项目中的图片采用相对路径，例如：

![](images/case14_topology.png)

Quarto 渲染网站时会把需要的图片和网页资源一起放到 docs/ 中。

发布 GitHub Pages 时，GitHub 发布的是完整的 docs/ 文件夹，而不是单独的 index.html，因此图片、CSS 和 Quarto 依赖资源会保持正确的目录关系。

八、最容易犯的错误

错误 1：只上传 index.html

不要这样做。

网站除了 HTML 之外还可能依赖：

  • 图片
  • CSS
  • JavaScript
  • site_libs
  • Mermaid 所需网页资源

错误 2：改完 .qmd 后忘记重新 render

每次修改后运行：

quarto render

再上传更新后的 docs/。

错误 3：移动图片但没有修改路径

如果：

images/case14_topology.png

被移动或重命名，index.qmd 中对应路径也需要修改。

九、推荐的最终使用方式

对这个项目，建议保留两份内容：

源文件：

index.qmd
styles.css
images/
_quarto.yml

用于你自己继续修改。

发布文件：

docs/

用于 GitHub Pages 对外展示。

这样最安全，也最容易理解。
